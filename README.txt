# KUNDAO Apparel Demo Website
昆道有限公司 跨境B端健身服装演示网站，SEO & GA4练手项目

## Brand Introduction
KUNDAO Apparel（昆道有限公司）is a manufacturer specialized in custom wholesale fitness and gym clothing, serving overseas fitness brands.

## Website Pages
1. index.html — Homepage（首页）
2. product.html — Product Page，健身短袖产品页，包含参数+FAQ+询盘CTA
3. blog.html — Blog article page，博客内容页，用于SEO长尾流量获取
4. case.html — Case study page，客户案例页，建立客户信任
5. landing.html — Landing Page，广告落地页，单一询盘转化目标

## GA4 Event Tracking
- `page_view`：页面浏览（GA自动采集）
- `cta_click`：追踪全部行动号召按钮点击
- `form_submit`：模拟询盘表单提交，在GA后台标记为转化事件

## Project Purpose
Practice SEO page types, user conversion path design, GA4 event tracking and conversion analysis.
Static website hosted on Github Pages.

## Tech
Pure HTML static site | Internal CSS | GA4 gtag tracking
